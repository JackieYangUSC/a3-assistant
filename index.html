599-a3 Test Assistant

599-a3 is a personal-assistant prototype built for a university course assignment (USC CSCI 599, Fall 2026). It is not a commercial product and is not offered to the public.

The assistant runs on a private server and is used only with one dedicated, temporary test Google account that contains fictitious data. It can:

  • read and summarize messages in the test Gmail inbox,
  • create draft replies in that inbox (a draft is sent only after a person explicitly approves it, and only to allowlisted addresses),
  • read events on the test account's Google Calendar to prepare daily briefings and meeting reminders.

Google access is requested with these scopes only: gmail.readonly, gmail.compose, calendar.readonly.
